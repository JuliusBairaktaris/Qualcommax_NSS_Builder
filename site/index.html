          Updates

          Images from this page update themselves to the newest release, keeping settings and every package you added:

          • LuCI: System > Firmware update, then Update now, or turn on Update automatically.
          • Shell: ppe-update check and ppe-update update.
          • Automatic, once a day at 04:00, a release at least a day old:
            uci set ppe-update.main.auto=1; uci commit ppe-update; /etc/init.d/ppe-update reload
